# Independent Cloudflare preview

Repository: https://github.com/kloudocean-kodex/wolco-original-sanctuary
Preview: https://wolco-original-sanctuary.pages.dev/

The GitHub-connected Cloudflare Pages project builds `main` using `npm run build`, output `dist`. CI runs 22 interaction tests, the production dependency audit, video tests and production build. No repository secrets or runtime environment secrets are required. The film route uses the narrow byte-range Pages Function. Static pages and ordinary assets use Pages directly.

This project is independent of the two editorial rebuilds. No custom domain or original-site DNS change is made. The preview remains noindex.
